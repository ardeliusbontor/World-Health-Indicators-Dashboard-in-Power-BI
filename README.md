# 🌍 World Health Indicators Dashboard

An interactive **Microsoft Power BI dashboard** designed to explore global health indicators, compare countries and WHO regions, and analyze health trends across years and demographic groups.

## 📌 Project Overview

This project transforms health data into meaningful insights through interactive visualizations, KPI cards, and dynamic filters. It helps users explore geographical patterns, compare health measurements, and understand changes over time.

## 📊 Dashboard KPIs

- **Countries Covered** — Number of countries in the selected data.
- **Indicators Covered** — Number of health indicators analyzed.
- **Latest Year** — Most recent year available.
- **Total Records** — Number of records in the dataset.
- **Reporting Records** — Records matching the selected reporting status.

## 📈 Charts and Visualizations

- **Line Chart:** Health trends over time.
- **Bar Chart:** Country comparisons.
- **Regional Chart:** Comparisons across WHO regions.
- **Map Visualization:** Geographic distribution of health indicators.
- **Clustered Bar Chart:** Comparison by sex.
- **Age Group Chart:** Analysis across age categories.
- **Donut Chart:** Data status distribution.
- **Table/Matrix:** Detailed health records.

## 🎛️ Interactive Features

- Country and WHO Region filters.
- Year and Indicator slicers.
- Sex and Age Group filters.
- Data Status filtering.
- Interactive tooltips and cross-filtering between visuals.

## 🧹 Data Preparation

Using **Power Query**, the data preparation process includes:

- Data type correction and standardization.
- Missing value and duplicate checks.
- Data cleaning and validation.
- Consistency checks for indicators and measurement units.

## 🎯 Project Objectives

- Compare health indicators across countries and regions.
- Analyze changes in health measurements over time.
- Explore demographic differences by sex and age group.
- Identify geographical patterns and reporting gaps.
- Present data through interactive visual storytelling.
